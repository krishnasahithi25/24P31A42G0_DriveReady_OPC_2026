# Day 2 – SmartTrip Travel Planner

## Task
Improve the SmartTrip Travel Planner chatbot by learning prompt engineering, conversation memory, JSON handling, and important Python concepts.

## Implementation
Day 2 focuses on making an AI chatbot more useful and reliable by improving the way it communicates with users.

The following concepts are covered:

- **Messages and Roles:** Understanding system, user, and assistant messages.
- **System Prompt:** Defining the chatbot's role, facts, rules, and response format.
- **Few-shot Prompting:** Using example inputs and outputs to guide the chatbot's responses.
- **JSON Handling:** Converting structured information into JSON format and Python dictionaries.
- **Conversation Memory:** Maintaining chat history so the chatbot can remember previous user messages.
- **Python Dictionaries:** Storing and accessing structured data using key-value pairs.
- **Functions and Type Hints:** Creating reusable functions with clear inputs and outputs.
- **Decorators:** Adding extra functionality to Python functions.
- **Exception Handling:** Using `try` and `except` to handle errors without stopping the program.

## How to Run
1. Open the Day-2 notebook in Google Colab.
2. Run the required setup and API configuration cells.
3. Execute the Python code cells.
4. Test the chatbot with different user questions.
5. Observe how prompts and conversation history affect the responses.
